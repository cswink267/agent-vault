# Admin UI (Phase 2a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Embed a passphrase-session Admin UI in `vault-server` at `/ui` so the owner can CRUD secrets, reveal/copy, lock/unlock, and view audit — without changing the bearer `/v1` agent API.

**Architecture:** New `internal/ui` package owns sessions, CSRF, HTML templates/static assets (`embed.FS`), and session-auth JSON under `/ui/api/*`. `api.Server.Handler` mounts the UI mux alongside existing `/v1` routes. Login verifies the vault passphrase (unlocking if sealed) and sets an HttpOnly session cookie.

**Tech Stack:** Go 1.22+ (module as-is), `html/template`, `embed`, vanilla JS/CSS, existing `internal/vault` + `internal/api` patterns, `httptest` tests. No Node/React build.

## Global Constraints

- Single-user host vault; host port **8200** → container `8080`.
- UI at `/ui`; agents continue bearer auth on `/v1` only (cookies must not authorize `/v1`).
- HttpOnly session cookie `agent_vault_session`; `SameSite=Lax`; `Secure` when TLS/`X-Forwarded-Proto=https`.
- Session store in-memory; idle TTL 12h or absolute 24h; CSRF on mutating `/ui/api/*`.
- List/search never return `secret`/`username`; reveal only via explicit `?reveal=1`.
- Never put secrets in URLs, audit payloads, or logs.
- Audit actor for UI: `ui` (or `ui:<8-char session prefix>`).
- No SPA/Node toolchain; no HTTPS/backup/rotation in this plan.
- Module path: `github.com/cswink267/agent-vault`.
- Stay on feature branch `cursor/admin-ui-design-dd00` (or continue it); do not create unrelated branches.

func TestSessionCreateGetExpireCSRF(t *testing.T) {
	s := ui.NewSessions(time.Hour, 2*time.Hour)
	id, csrf, err := s.Create()
	if err != nil || id == "" || csrf == "" {
		t.Fatalf("%v %q %q", err, id, csrf)
	}
	if !s.Get(id) {
		t.Fatal("missing session")
	}
	got, ok := s.CSRF(id)
	if !ok || got != csrf {
		t.Fatal("csrf mismatch")
	}
	s.Delete(id)
	if s.Get(id) {
		t.Fatal("deleted session still present")
	}
}

**Page behavior:**
- `GET /ui` → redirect `/ui/` or list
- `GET /ui/login` → login form (public)
- `GET /ui/` or `/ui/secrets` → list (auth)
- `GET /ui/secrets/new` → new form (auth)
- `GET /ui/secrets/view` with query `name=` **or** path `/ui/secrets/view/{name}` — prefer path `/ui/s/{name}` for detail to avoid clashing with `/ui/api/secrets/{name}`. Use **`GET /ui/secrets/detail`** with JS reading `?name=` only for navigation after list click — **better: `GET /ui/s/{name}`** for HTML detail.
- `GET /ui/audit` → audit page
- `GET /ui/static/` → file server from embed

**JS responsibilities:** login submit; list search; create/update/delete; reveal/copy; lock/unlock; attach `X-CSRF-Token` from CSRF cookie on mutating fetches.

**CSS:** CSS variables; calm utility look; no purple gradient / glow / emoji; readable forms; works narrow width.
